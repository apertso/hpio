Which app should you choose?

Choosing a finance tracker just got easier. We compared the established ZenMoney with Hochu Plachu to see which features you get and what they cost.

Feature comparison

Feature ZenMoney Hochu Plachu
Price Paid subscription. Completely free.
Getting started Cloud account required. Start on the web or on Android.
Self-hosting Unavailable. Optional via Docker.

ZenMoney as the established option

Pros

  • Automatic imports. Built-in connections to banks.
  • Popularity. A large user community.

Cons

  • Price. Full access requires a paid subscription.
  • Privacy. Your data is stored on the company’s servers.

Hochu Plachu for flexibility and choice

Pros

  • Free for everyone. All features are available at no charge.
  • Convenience. A full Android app and a web version.
  • Flexibility. Set up your own tracking rules without limits.

Cons

  • Rule setup. You need to set up the initial rules for reading messages manually.
  • Advanced setup. You need to set up Docker if you choose to self-host.

The verdict

Hochu Plachu offers a free finance tracker on Android and the web. If you decide later that you want more control over where your data lives, you can take your data with you and run the app on your own server using Docker.
